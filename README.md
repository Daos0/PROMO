# PROMO - описание проекта и возможностей

Понятное описание системы: что это такое, как устроено и что умеет AI-агент.
Здесь нет кода и секретов - только документация для тех, у кого проект уже есть.

## Коротко о проекте

AI-ассистент, который отвечает клиентам **по вашей базе знаний** (RAG), работает
круглосуточно в сайте, Telegram, WhatsApp и Bitrix24, собирает заявки и передаёт
дело менеджеру, когда нужно. Управляется через веб-панель - без программиста.
